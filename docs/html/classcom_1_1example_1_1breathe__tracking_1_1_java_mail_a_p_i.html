Detailed Description

Gestiona el envío de correos electrónicos en segundo plano. <Void, Void, Void>.

Esta clase evita el bloqueo del hilo principal (Main Thread) al realizar operaciones de red. Utiliza la biblioteca JavaMail para conectar con el servidor SMTP de Gmail.

Características principales:

  • Autenticación segura mediante "Contraseña de Aplicación" de Google.
  • Construcción de mensajes MIME multipartes (soporte HTML).
  • Inyección de estilos CSS para correos corporativos/profesionales.
  • Notificación visual (Toast) al finalizar el envío.

◆ doInBackground()

Void com.example.breathe_tracking.JavaMailAPI.doInBackground ( Void... params)
protected

Lógica de conexión y envío en hilo secundario.

  1. Configura las propiedades (Properties) para TLS/SSL en el puerto 465 de Gmail.
  2. Inicia sesión (Session) con las credenciales del robot.
  3. Crea el objeto MimeMessage.
  4. Asigna un alias ("⚠️ Alertas Breathe Tracking") al remitente.
  5. Genera el contenido HTML llamando a construirHTML.
  6. Envía el mensaje mediante Transport.send().
Parameters
paramsVoid (no se usan parámetros variables).
Returns
null

Configuración del remitente con alias visual personalizado para apariencia profesional.

Establece el contenido como HTML con codificación UTF-8 para soporte de tildes.
