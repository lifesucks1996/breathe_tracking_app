11/**
12 * @class TrackingDataHolder
13 * @brief "Tablón de Anuncios" reactivo de la aplicación (Singleton + LiveData).
14 *
15 * @details
16 * Esta clase implementa un almacén de datos centralizado que desacopla el productor de datos
17 * (@ref SensorTrackingService) del consumidor (@ref SesionSensorActivity).
18 *
19 * **Arquitectura:**
20 * Actúa como un bus de eventos en tiempo real. Al usar `MutableLiveData`, garantiza que:
21 * 1. La UI siempre observe el último dato disponible.
22 * 2. No se produzcan fugas de memoria (Memory Leaks) si la actividad se destruye.
23 * 3. La actualización de la interfaz sea segura respecto a los hilos (Thread-safe) usando `.postValue()`.
24 *
25 * @author Sandra (Arquitectura LiveData - 29/10/2025)
26 */
27
28public class TrackingDataHolder {

30 private static final TrackingDataHolder instance = new TrackingDataHolder();
